# Heart model attribution

`VH_M_Heart_v1.1.glb` is the male reference heart from the **Human Reference Atlas (HRA)
3D Reference Object Library**, made by the HuBMAP consortium. It was built from the Visible
Human Project male dataset.

- Source: https://github.com/hubmapconsortium/ccf-releases/tree/main/v1.1/models
  (file `VH_M_Heart.glb`, release v1.1)
- Licence: Creative Commons Attribution 4.0 International (CC BY 4.0), as stated for HRA
  data on https://humanatlas.io. Please check the current terms there before redistribution.
- Credit line to use: "3D reference heart from the Human Reference Atlas, HuBMAP consortium (CC BY 4.0)."

The file is stored unchanged. `app/anatomy` converts it to millimetres, closes small holes
(MeshFix) and cuts it; those steps are described in the generated PDF atlas.
